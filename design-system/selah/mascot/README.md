## 本轮修正与核验

- 以原始 C 版右上角为身份依据，恢复圆润种子身体、身体侧面的小手、短小脚部、棕色点眼及与头顶连接的单芽。
- 十格采用同一单芽阶段；眨眼、弯眼微笑及轻抬手表达状态，没有混入双叶、花朵或另一套手脚。
- 二次修订将「准备聆听」「录音中」恢复为正面站姿，减少倾斜导致的体型差异；不靠身体拉长或压扁区分状态。
- 目视核对角色完整性、叶柄连接、五官位置、脚部基线及十个中文标签，未发现明显缺肢、漂浮叶片、文字裁切或惩罚性表情。
- PNG 读取与完整性检查通过；复制到项目后的 SHA-256 与生成源文件一致。

## 运行时边界

AI 状态图仍属于视觉验收稿，独立生成的姿态不保证逐像素相同。真实动画应由同一套身体、眼睛、小手和叶片图层驱动，并固定连接锚点；不轮播这十个独立角色来制造动画。

待机、准备聆听和录音中的静态外观刻意接近，实际运行时用轻微呼吸、专注停顿及录音界面反馈区分；播放中和完成状态用短促小幅回应表达，不持续大幅跳动。具体时长、图层导出、透明边缘以及 Web 实际播放效果仍待接入后验收。

实际生成提示词与参考顺序见 `prompts.md`；动作 ID 与状态映射见视觉修订规范。
