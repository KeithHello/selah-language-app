# Seed V3 材质与造型探索

日期：2026-09-05。

用户认为上一轮形象质感仍不合适，明确要求重新设计并尝试多种类型。本轮交付四种独立视觉方向，让用户比较后再收敛；不将任何候选标为已选定或直接替换 Web 运行素材。

## 本轮设计依据

- 保留 Selah 的安静陪伴、自然成长、适合成人学习的气质，以及与暖米色界面协调的配色。
- 用户本次允许重新设计，因此本轮开放调整轮廓、颜色和材质；上一轮对 C 版形体的严格复刻要求不用于这些新候选。
- 质感通过造型、真实材质响应、克制的光照与细节表达，不通过均匀叠加粗颗粒表达。
- 每个方向独立生成一张主形象与两种状态的展示板；同一板内保持角色身份和材质一致。
- 本轮仅制作图片与对应记录，不变更应用代码、运行依赖或动画方案。

## 交付与核验

- 四张最终图均为 1536 × 1024 的 RGB PNG，带暖白背景；每张包括一张主形象及「专注」「开心」两个状态。
- 目视检查四种材质区分、角色轮廓、完整性、叶柄连接、两种表情与标签；A 款初稿背景过暗，已通过图像工具修订背景与文字对比。
- 四张 PNG 均通过文件完整性检查，项目副本与生成源文件的 SHA-256 一致。
- V2 标准图与十状态图保留为历史记录，用户本轮已反馈质感不合适，不能当作已采用的设计。
- 没有替换 Web 运行素材，没有生成或验证可播放动画。独立姿态图不保证逐像素一致，定型后仍需使用同一套图层或模型制作状态。

## 视觉判断

以下是本轮设计判断，尚非用户的最终选择，也不代表 Web 小尺寸验收结果。

| 方向 | 表现 | 建议 |
| --- | --- | --- |
| A 细腻软胶 | 杏色与绿叶形成清楚对比；柔和体积与小表情兼具亲近感和活力 | 优先作为学习伙伴方向继续打磨 |
| B 温润陶瓷 | 奶白瓷体、青瓷叶片、低矮轮廓，安静而克制 | 偏成熟、安静的备选方向 |
| C 短绒织物 | 短绒、刺绣眼睛与缝线强化触感和陪伴感 | 偏温柔治愈的方向 |
| D 磨砂琥珀 | 无肢体水滴轮廓、暖色透光边缘，更接近艺术摆件 | 实验性方向，暂不优先作为主吉祥物 |

实际提示词和每次生成文件见 `prompts-v3.md`。
