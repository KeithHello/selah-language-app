# 网站性能 P0/P1 优化实施计划

> 状态：代码、本地自动化验证与 Release 浏览器冒烟已完成；未部署。
> 范围：Flutter Web 页面重建、轮询、本地快照、云同步、静态缓存与动画精灵资源。

## 目标

减少空闲页面无效轮询和整页重建，降低本地快照复制与云端同步的重复工作，并缩小动画资源体积、让跨版本 Service Worker 复用未变化的静态文件。

## P0：交互与后台开销

- [x] 缓存 `ThemeData` 与根主题，取消没有用户价值的主题过渡动画。
- [x] 轮询改为单次自调度：播放、录音、加载或循环听活跃时维持 450ms；空闲时降至 5 秒。平台状态和播放语义未改变时不触发页面级通知；播放进度由独立监听器更新。
- [x] 活动心跳继续发送到远端，但不再产生本地学习事件、本机快照写入或同步任务。

## P1：同步、快照与静态资源

- [x] 句子、词汇和学习事件按各自时间游标增量拉取，并重叠 2 秒容忍时间戳边界；以待同步 ID 补拉本地未确认记录。
- [x] 新句子与词汇按每批 100 条写入；保留现有乐观并发冲突校验，并在同步期间记录再次修改的记录，避免确认响应清掉新编辑的待同步状态。
- [x] 快照复制直接从存储结构解析，不再经 JSON 字符串往返；写入 IndexedDB 时直接传递 `toStorage()`。
- [x] Web 字体资源明确列出，仅打包 Roboto、Plus Jakarta Sans 与 Noto Sans SC 子集。
- [x] 构建生成每个静态文件的 SHA-256 清单；Service Worker 仅在哈希相同时从旧缓存复用资源。最终写入 Build ID 后重新计算首页哈希；仅预缓存当前浏览器使用的 CanvasKit 变体与首屏姿态。
- [x] 50 个 16 帧动画姿态转为 q85 动画 WebP，保留源帧时长与无限循环；源 PNG/GIF 文件不删除。产物合计从 92,179,495 字节降至 21,774,008 字节，减少 76.4%。

## 本地验证结果

- `flutter analyze --no-pub`：通过。
- `flutter test --no-pub`：439 项通过。
- Node 浏览器桥接、循环播放、卸载保护、Service Worker 与构建配置测试：45 项通过；WebP 资产契约测试通过。
- 原始 50 张 RGB 设计母版逐张验证哈希、尺寸与颜色格式，未改动。
- 最新代码以 Release 模式构建，版本 `1.9.0`、Build ID `62b700ce76fa0bcf`。预缓存包含 123 项资源、152 个有效哈希，哈希全部匹配；浏览器本地冒烟中 Service Worker 已接管，缓存 101 项。
- Chromium 的 WebCodecs 验证 WebP 动画为 16 帧，逐帧时长与源素材一致。
- 本地静态服务器冒烟测得 `responseStart` 247ms、`domInteractive` 291ms、`loadEventEnd` 950ms。该结果受本机、未压缩静态服务器和访客构建影响，不作为生产 Core Web Vitals 或前后对比结论。
- 设计母版 PNG 不在隔离 worktree 中；资产测试的母版子项因此通过只读主工作区核验，WebP 子项在 worktree 中直接通过。
