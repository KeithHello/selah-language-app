## 1．最终商业规则

| 权益 | 免费示例 | 7 天个性化试用 | 月会员／赠送会员 |
|---|---|---|---|
| 价格 | 免费 | 免费，每账户一次 | 购买为 39.9 元／月；赠送与补偿收入为零 |
| 有效期 | 长期学习已有示例 | 首次个人表达成功并在服务端保存后 168 小时 | 每个有效会员月账期 |
| 新增个人表达 | 不提供 | 30 条 | 每期 300 条 |
| 新增 AI 配音 | 复用示例音频 | 3000 个字符 | 每期 30000 个字符 |
| 录音转写 | 不提供 | 5 分钟 | 每期 60 分钟 |
| 长文整理 | 不提供 | 3 次 | 每期 30 次 |
| 已有内容学习 | 可用 | 到期／触顶后仍可用 | 到期／触顶后仍可用 |

四类权益分别计量，不能相互兑换。表达按服务端成功保存条数计量；批量生成按实际成功条数计量，模型费用只记录一次。长文整理与后续表达生成是两类动作。配音按实际提交供应商的完整文本计字符，包含空格、标点、母语音轨、新声线和主动重生成；重复播放与同结果缓存命中不新增生成权益。转写使用服务端验证的真实时长。

试用首次付费调用前建立唯一预备记录，失败费用记入同一预算；首次表达保存成功再激活 168 小时，客户端断线不影响起算。预备期整理／转写照常受额度和预算限制。退出、换设备、删除本机数据或失败重试都不重新赠送试用；多账户仍受平台试用池保护。

月会员采用主动购买／续购，不默认自动扣款。没有有效或排期月会员时，服务端确认到账后开始；已有付费、赠送或补偿期间时，购买顺延到确认的时间线末端，付款前显示实际开始日期。一个月为一历月，保留月末锚点，UTC 存储并显示用户时区；续购、补发、登录和自然月首日不能清零当前用量。

在途请求始终结算原账期；试用转会员不叠加余额。退款撤销对应权益并保留事件，晚到成功回调不能复活已退款订单。已有文字和本机音频可继续学习；没有缓存的云端音频仍受网络与下载服务可用性影响。

## 2．费用结论与保护边界

| 情景 | 7 天试用 | 月会员每期 | 当前结论 |
|---|---:|---:|---|
| 四项权益用满，每次调用一次 | 约 0.9103 元 | 约 9.3129 元 | 条件测算 |
| 每次均发生一次额外收费重试 | 约 1.8206 元 | 约 18.6258 元 | 压力情景，非实测最高值 |
| 拟采用的模型预算 | 2 元 | 20 元 | G01／G02 通过后才能启用 |

以上沿用 2026-09-10 的模型费率记录和 USD／CNY＝7 的假设，并采用主设计的文本长度上限；转写仍是分钟估价。本次整合没有重新核价。费率、公式与来源见 [详细设计第 6 节](../specs/2026-09-10-membership-cost-control-design.md) ，实施与开售前重新核验。

39.9 元减去 20 元目标得到的 19.9 元只是模型预算后的差额，不是净利润；还要覆盖支付费、基础设施、流量、税费、退款及赠送／试用成本。整个平台的最高总支出目前无法给出已经验证的固定数值。

| 保护对象 | 强制机制 |
|---|---|
| 用户每类权益 | 已交付＋在途预占＋本次需要不得超过上限 |
| 用户与平台模型费用 | 已结算＋未决尝试上界＋本次调用上界不得超过对应预算 |
| 试用、赠送及已售容量 | 新发权益前登记完整期间的预算承诺；不足先停止新增试用／销售／赠送 |
| 重复、并发和失败 | 数据库原子操作、请求幂等与负载哈希、一次性发送认领；未知费用不按超时清零 |
| 重试 | 一个首发加最多一次额外供应商尝试，每次单独预占；已拿到结果的保存重试复用结果 |
| 存储与下载 | 上传字节预占、私有音频、授权下载网关、有界 Range、本机缓存与独立流量预算 |
| 价格与服务状态 | 过期价格、未知模型、汇率越界、预算配置缺失或预占服务故障时关闭受影响的新调用 |

费用用整数 `nano_usd` 保存并以字符串传输，上界向上取整，可用预算换算向下取整。未来权益容量承诺、调用预占与实际费用是同一责任的不同阶段，转换时不能重复相加。未发生的承诺可以按规则释放，已发送或未知收费必须保守保留。任何管理员操作也经过这些检查。

服务端输入边界：单句源文本最多 500 字符、完整输入预算 4096 tokens、输出最多 2048 tokens；长文最多 4000 字符、完整输入预算 16384、输出最多 4096；批量 1—5 条，输出上限为 `min(n * 2048, 8192)`。转写单次保持 180 秒／10 MiB，并证明真实收费上界。拟定单个 MP3 5 MiB 上传限制须以最长合法音频验证。缺少可信上界的入口不能先付费调用再检查。

## 4．Dashboard 会员管理

| 管理区域 | 首版能力 |
|---|---|
| 总览 | 保留学习与 API 统计；增加付费／赠送会员、试用、核实收款、退款、赠送月数和预算承诺 |
| 用户与会员 | 按 ID／邮箱搜索、状态／到期筛选、分页；详情显示权益时间线、来源和操作面板 |
| 订单与补发 | 查询支付及权益发放状态、补发已购权益、登记已核实的人工收款、查看退款状态 |
| 用量与成本 | 管理员查看详细用量、个人／平台预算、估算／供应商记录／未知／在途和关联请求 |
| 异常与服务控制 | 处理未发权益、未知费用及异常调用；按原因暂停／恢复新增生成或新试用／销售 |
| 操作日志 | 按用户、操作者、订单与日期追溯前后状态、原因、预算变化和处理结果 |

后台提供六类明确操作：已购补发、人工核实收款、赠送、客服补偿、撤销误赠、暂停／恢复生成。会员身份由有效权益推导，不能任意切换 `is_member`；管理员名单与产品月会员完全独立。首版区分后台查看与后台管理权限，未配置写权限时只读。

赠送提供 1／3／6 个月快捷项和 1—12 整月输入；非会员立即开始，现有会员顺延。三个月是三个独立月账期，每期恢复同版权益，本期消耗不清零。赠送收入为零，创建时占用赠送池和未来容量；若每月 20 元目标通过证明，赠送三个月预留 60 元模型容量，实际调用仍逐次预占。

已购补发重新核验原订单，只恢复缺失权益，不从补发当天重新赠送；人工收款必须具有受控渠道、唯一交易编号、原价金额、月数、时间、凭证引用和原因，单独标为人工核实。回调、查单、人工补发与赠送共享幂等和时间线锁。历史冲突进入人工核对，不覆盖有效期间或重复确认收入。

撤销误赠只处理指定赠送尚未使用的部分，保留实际费用、在途预占和审计，不悄悄挪动其他已确认期间；暂停和恢复不重置账期／预算。用户内容保持可学习。后台操作先预览真实日期及预算影响，再提交并重新检查版本；结果与审计在同一事务中保存。

用户详情采用「会员时间线＋关联订单＋操作面板」，详细用量与成本仅在管理员区展开。赠送表单包含用户、月数、起止时间、每期权益、当期影响、费用影响及必填原因；提交中禁重复，状态变化要求重新确认，成功显示审计编号。撤销、暂停和预算变更明确展示影响并二次确认。

当前源码入口是同源 Web 应用的「设置→打开管理台」，并支持 `/#/admin` 深链接；本地服务端口由启动命令决定（既有开发入口示例为 `http://127.0.0.1:5191/#/admin`）。该 URL 只负责导航，管理员真实数据和写操作仍由服务端权限与 migration 提供，未把本地构建冒充远端可用。
