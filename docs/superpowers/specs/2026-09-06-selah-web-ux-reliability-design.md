# Selah Web 整体交互与可靠性改造设计

## 状态与目标

2026-09-06：主人认可整体 UI／UX 审查，告知 Supabase 已启动，并授权基于审查结果开展完整开发。本文将已认可方向细化为跨页面行为、数据边界和验收条件；详细设计待主人审阅，尚未修改产品代码。

目标：保留 Quiet Growth 品牌与现有 Flutter Web 架构，让用户能够安全、连续地完成「表达→生成→聆听→理解与开口自评→复习」，并准确知道数据保存在本机还是已同步云端。

## 一、范围与方案选择

推荐采用「现有架构内分阶段改造」：保留五个顶层入口、业务控制器、账户隔离存储与现有 Supabase 表，围绕审查发现的操作问题补齐状态和交互。每阶段独立测试，不一次替换整个应用。

比较方案：

- 全面重写导航和状态管理框架，会扩大数据回归与现有角色接入的冲突范围；不采用。
- 只调整颜色、字号与间距，无法解决输入覆盖、播放无控制与同步误导；不足以满足本次完整改善要求。

本轮包含：首次引导、今天、聆听、练习、笔记、设置、跨页播放控制、手机导航、本机输入保护、同步反馈、成长进度与可访问性。

本轮不包含：旧 Flutter 原生 Fixture 客户端切换后端、SwiftUI 重构、发音自动判分、新目标语言、Web Push 后端、重新生成角色素材、数据库迁移、公开部署。

不新增 Flutter 包或全局依赖，不更改 `.env`、密钥、CI、Supabase schema／RLS／认证策略。确实需要这些变化时另列最小方案取得确认。

五阶段五十姿态是另一项已授权工作；本轮复用其正式展示接口，不覆盖 `plush_companion.dart`、姿态映射、PNG、gallery 或其进行中的改动。

## 二、Supabase 恢复后的事实基线

2026-09-06 使用当前项目配置完成只读检查；凭据未打印、未写入文档或源码。

| 检查 | 本次实际结果 | 能证明什么 |
|---|---|---|
| 项目域名 DNS | 解析成功 | 之前的 NXDOMAIN 阻塞已解除 |
| `GET /auth/v1/settings`，使用现有 publishable key | HTTP 200，邮箱认证启用 | 项目认证入口与公开配置可用；不等同真实用户登录成功 |
| `HEAD /rest/v1/seed_sentences?select=id` | HTTP 200，精确数量 30 | 云端种子句子目前存在 |
| `HEAD /rest/v1/audio_manifests?select=id&seed_sentence_id=not.is.null&generation_status=eq.ready` | HTTP 200，精确数量 120 | 云端有 120 条就绪种子音频清单；本轮未重新下载全部文件校验 |
| `HEAD /rest/v1/sentences?select=id` | HTTP 200，精确数量 0 | 检查时该表没有用户句子；不代表浏览器中的访客资料不存在 |
| `HEAD /rest/v1/learning_events?select=id` | HTTP 200，精确数量 1 | 检查时该表存在 1 条事件；未读取事件正文 |

数据计数在受控本机使用既有服务端凭据，按官方协议仅请求 `HEAD` 与 `Prefer: count=exact`，不读取用户句子正文，不写入数据。该检查不代替普通登录用户的 RLS、写入与同步验收。

先前管理 API 的 401 与本次业务 API 的恢复是不同事实；当前开发不依赖管理 API，也不轮换管理凭据。真实 AI、TTS、转写、跨设备闭环仍需独立验证。

## 三、结构与数据约束

- `SelahFlutter/lib/web/learning_controller.dart` 继续负责账户、保存、同步与媒体业务时序。
- `SelahFlutter/lib/web/domain/` 放置必要的输入草稿、同步展示与成长进度纯逻辑；仅抽取本次需要独立测试的状态，不做无关重构。
- `SelahFlutter/lib/web/ui/` 放置页面及小型导航／播放器／反馈组件，复用现有样式和角色接口。
- `SelahFlutter/lib/web/data/` 继续适配现有 Supabase 字段与本机存储；客户端不得持有服务端 secret 或 OpenAI key。
- `SelahFlutter/web/selah_bridge.js` 只补必要的浏览器生命周期与导航适配，不缓存认证响应或 AI 请求。
- 本机草稿扩展采用现有账户快照的可选 JSON 字段；兼容旧备份，不增加 IndexedDB 表或数据库版本迁移。云端同步不上传未提交的输入、原始录音或 UI 临时状态。
- 当前账户切换后，旧请求不得修改新账户的输入、选句、播放、反馈或同步状态。
- 分别追踪本机保存版本与可同步业务版本；仅编辑本机草稿不得让云端一直显示待同步，也不能把草稿写入成功算作业务同步完成。
- 现有学习事件为追加型记录；不得通过删除已同步事件来实现撤销。

## 四、详细交互

### 4.1 输入、生成与录音保护

输入区保持可编辑。提交时固定账户、输入版本、文字与请求 ID；请求完成只清理与提交版本相同的内容，生成期间的新编辑必须保留。

未提交输入按账户自动保存，连续输入采用短延迟合并写入。只有 IndexedDB 事务成功才展示「本机已保存」；写入中或失败时不冒充已保存。页面关闭／更新前仍有未保存编辑时提供提示；不承诺浏览器被强制终止后尚未完成的写入可恢复。

长文分段同样保存编辑版本；部分成功与失败的段落分别展示，不在部分失败时清空全部原文，也不重新提交已成功段落。

录音操作包含「开始、停止并转文字、取消」；取消当前录音须明确告知会丢弃该段。待转写失败时提供「重试、放弃」，新录音不得静默覆盖待重试录音。

转写结果先展示为可编辑结果，默认使用「插入输入框」在当前光标处插入；若选中已有文字，默认不以转写替换该选区。另提供「替换全部」，执行前确认，保留替换前文字供当前操作撤销。长度超过 4000 字时展示超限与编辑入口，不静默截断。

原始录音仍是当前页面的临时数据，不加入云同步或 JSON 备份；界面明确提示刷新会丢失尚未完成的转写。持久化录音属于另行隐私与存储设计，不在本轮暗中增加。

### 4.2 登录入口与同步状态

访客进入今天页就能看到「本机学习」状态。生成、长文整理与转写旁展示登录要求和就地登录入口；登录弹窗取消后保留草稿。

登录后检测访客资料，展示可导入的数量与「导入／暂不导入」，默认不把访客内容混入新账户。导入成功区分本机合并与云端同步两个结果。

如果登录从有输入的今天页发起，访客输入先留在访客分区；成功登录后明确提供「将刚才的输入带入此账户」操作。未选择带入时不覆盖账户已有草稿，并提示原输入仍保留在本机访客空间。

同步显示遵守以下优先级：

1. 本机保存失败：显示错误与重试，不显示已保存。
2. 云端未配置／未登录：显示本机保存范围和进入登录的操作。
3. 同步中：显示进度，不依据浏览器联网提前显示成功。
4. 最近同步失败：显示失败原因、重试及本机保留说明。
5. 有待同步修改：显示待同步；离线时补充网络状态。
6. 当前可同步版本全部完成：显示最近同步成功时间。

浏览器的 online 信号仅表明网络条件；不将它当成 Supabase 健康检查。最近成功时间也不代表此后新增内容已上传。

草稿保留在本机时单独说明；不将「已同步」解释成原始录音、离线音频和所有未提交输入均已云端备份。

### 4.3 导航、手机列表详情与播放

保留五个顶层入口；桌面侧栏、手机底部导航。使用 Flutter 内置导航与 hash 地址，不新增路由依赖，不要求静态服务器增加路径重写。

主要页面与已保存句子详情拥有可恢复位置；句子 ID 按当前账户已加载内容验证。无权访问或不存在的句子返回有解释的列表，不泄露其他账户资料。

手机聆听与笔记采用「列表→详情」，详情有明确返回按钮；浏览器返回也应回到此前列表。返回时保留搜索、筛选和列表滚动位置，顶层切换不清空今天页草稿。

桌面在主内容区域足够宽时展示左右分栏；不足时退回列表详情结构。右侧陪伴区域不得挤压播放器主操作。

「去聆听这句」进入该句详情并启动用户本次主动请求的播放；播放被浏览器拒绝时保留详情、提供可点击的播放按钮与原因。

跨页播放显示迷你播放器：当前句子、播放／暂停、进入播放详情、关闭。选中句子和正在播放的句子分别管理；不能把旧音频进度标到新选中的句子上。开始另一段音频前停止旧会话，真实完成事件保持一次性计数。

播放结束提供「再听一次」和「练习这句」，不自动跳页或替用户评分。播放速度控件支持换行，不溢出窄屏。

### 4.4 练习与操作撤销

练习明确为「开口自评」，不增加或暗示自动发音判分。区分尚未学习、暂无到期复习、今日已完成、自由练习四种状态；自由练习不显示「0 句在等你」。

支持重听、显示／隐藏答案、跳过当前句。跳过只影响当前练习队列，不修改掌握度、不生成学习完成事件。

评分采用可撤销确认态：选择评分后展示结果和「撤销／下一句」，最后一张为「完成并保存」。在点击下一句或完成前不提交该评分，不写云端学习事件；关闭或返回时询问保存评分还是放弃当前选择。成功持久化后才增加成长和完成数。

这种撤销只适用于当前尚未提交的选择，不承诺撤回历史已同步事件，不修改追加型事件 RLS。保存失败保留当前选择并允许重试，不能跳走后丢失评分。

### 4.5 笔记

保留搜索与分类，补充明确的状态筛选和清除筛选入口；搜索框筛选图标必须真的打开筛选，不能是可点击外观的装饰。

空状态区分「尚无笔记」和「当前筛选无结果」。手机详情的主操作为「听这句／练这句」，夜间预览放入次要操作。

词汇状态使用明确选项，不再依赖小标签循环。触控区至少 44 逻辑像素，并提供文字和可访问名称。支持当前状态操作撤销；若已发生新的状态修改或账户切换，旧撤销不得覆盖更新。

中英文学习内容支持选择复制。暂不新增批量删除、历史清理或新的云端归档协议。

### 4.6 首次引导

角色名称预填可修改的默认值，并明确是「精灵名字」；不把它作为对用户本人的称呼。

保留恰好三句的幂等起步规则。推荐组合从具有内置音频的内容中选择，兼顾不同场景；提供分类与独立试听按钮，选中与试听是两种不同操作。

选满三句时告诉用户先取消一项即可替换，而不是让未选卡片看起来仍能添加。提供「已有账户，登录继续」，登录并读取云端引导状态后再决定是否需要新手流程，避免回访用户被要求重复初始化。

引导完成后进入第一句聆听详情，突出播放按钮；不依赖无用户手势的自动播放。试听不改变学习次数或成长。

### 4.7 设置与反馈

登录／注册使用字段级错误、密码可见切换、邮箱键盘、自动填充、提交状态、显式关闭与键盘提交。确认邮件是等待操作状态，不是笼统红色错误。

找回密码使用既有 Supabase Auth SDK 的恢复邮件与恢复会话流程；邮件跳转只使用已允许的应用地址，不自行修改认证重定向配置。若实际托管地址未配置，明确列为上线验收条件，不伪造发送或恢复成功。

声线使用现有内置样例试听，试听不计学习完成；当前声线是否已缓存按真实句子／声线判断。名称编辑与保存反馈对应当前账户，在同步／导入后刷新已保存值，保留尚未提交的本地编辑。

备份导入先校验并展示新增、合并与冲突数量，以及不包含音频文件／原始录音的范围；确认后原子合并，不部分导入。访客资料导入仅对登录用户开放。导出说明实际包含哪些数据。

安装按钮根据浏览器支持与已安装状态显示；前台提醒继续明确关闭网页后不保证送达。初始化失败展示重试或恢复指引，不无限显示旋转图标。

### 4.8 字号、对比度、成长与性能

保留暖米背景和现有品牌色；新增或调整功能性前景／按钮色，不把低对比品牌装饰色直接用作小字。

正文目标 16 逻辑像素，辅助信息 12—14，导航标签至少 12；支持 200％文字放大并允许布局换行。普通功能文字对比度至少 4.5∶1，大字至少 3∶1。高频触控区目标 44—48 逻辑像素；这是产品触控目标，不混称为 WCAG 2.2 AA 的 24 CSS 像素最低规则。

图标按钮有可访问名称，键盘焦点可见、顺序符合阅读顺序，页面切换后焦点到标题或主内容。失败消息可被辅助技术读到，成功消息不抢焦点；减少动态效果设置继续有效。

成长阶段与进度使用同一业务规则：未完成引导为起步；已完成引导且学习次数小于 5 为 sprout；5—14 为 leaf；15—29 为 bud；30 及以上为 bloom。显示当前阶段与距下一阶段次数，最终阶段满格；不改变既有成长阈值或五阶段素材映射。

列表使用惰性构建；播放轮询只在相关会话中更新需要的界面，避免全页面固定频率重建。实际性能在浏览器测量后报告，不仅凭源码推断提速。

## 六、验收矩阵

每个行为先补失败测试，观察缺口，再实施最小修复并运行相关测试。

| 场景 | 必须观察到的结果 |
|---|---|
| 生成期间继续编辑、失败后重试、部分分段成功 | 新编辑不被清空，已成功请求不重复生成，失败内容可恢复 |
| 未保存输入刷新／跨页／登录／退出／换账户 | 已落盘草稿恢复，账户隔离；未完成保存不显示成功 |
| 转写插入、替换、超限、取消、失败再录 | 不静默覆盖或截断，取消释放媒体轨道，失败录音不会被新录音默默替换 |
| 联网但 Supabase 失败、离线、同步期间再次编辑 | 不误报连接或同步成功，重试保留本地修改，不串账户 |
| 句子数量 0／3／30／100，宽度 320／390／768／1280／1440 | 列表和详情可直接操作，无水平溢出；返回保留筛选及位置 |
| 跨页播放、切句、试听、暂停续播、结束事件重复到达 | 当前播放对象正确，随时可暂停；试听不计成长，真实聆听只计一次 |
| 练习空状态、自由练习、跳过、撤销、评分保存失败 | 文案与状态一致；不伪造完成；未提交评分不写事件 |
| 备份旧版本、损坏／超限／重复／跨账户导入 | 先校验后确认，原子合并，拒绝时现有资料不变 |
| 键盘导航、200％文字放大、Reduce Motion | 焦点可见、标签可读、控件可达、没有关键操作被遮挡 |
| 成长次数 0／4／5／14／15／29／30／31 | 阶段和进度一致；最终阶段不取模回退 |

```powershell

```

执行目录为 `SelahFlutter/`。其他已存在的角色、缓存与桥接测试也进入最终全量回归；不得用旧日期的通过记录替代本轮执行结果。

浏览器先使用隔离的本机测试资料验证，再以专用测试账户验证真实服务。私密账户和原始输入不得进入日志或截图。服务端凭据只用于受控只读检查，不能放进浏览器以绕过正常登录或 RLS。

## 七、真实服务与外部确认边界

上线前需完成真实登录→生成一条句子→TTS／下载→真实播放结束→保存自评→另一浏览器会话读取的闭环；跨浏览器同账户只证明跨会话同步，真机跨设备另行报告。

现有 `speech-transcribe` 源码不代表已部署；实际调用若发现函数缺失、服务端 secret 失效、邮件跳转未配置，报告具体原因与最小需要的变更。未取得部署／密钥／认证配置授权前，不执行这些外部变更。

真实 AI 验收涉及测试数据与用量；使用专用测试账户和明确的小样本。已有远端验收脚本的计费确认开关仍必须遵守，不批量生成 120 条新音频，不删除历史测试数据。

本地产品实现与外部验收分开记录。远端条件未满足时继续完成不受影响的本地开发，不声称服务已全通，也不通过 Mock 冒充真实成功。
