## 角色外观约束

- 核心形象：温和的种子精灵，紧凑圆润、下部略宽，头部没有细长脖子。
- 材质：燕麦奶油色短绒织物、可感知但不过粗的纤维方向、低调缝线；不能变成陶瓷、软胶或琥珀。
- 五官：深棕刺绣眼睛、小弧线笑容、克制腮红；专注状态避免厚重困倦眼睑。
- 肢体：靠近身体侧面的小手、藏在底部的小脚；保持连接位置和大小，不随表情重新塑形。
- 叶片：一个连接头顶的短叶柄与鼠尾草绿叶；叶根固定，状态变化不能变成耳朵、漂浮图标或突然多一片叶子。
- 基准图是当前单芽外观。现有成长记录和升级规则继续保留；生产接入时将成长装饰对齐到 C 的头顶锚点，更多阶段外观需补齐对应素材，不能直接叠加悬空图标。
- 正面以已选图为准；补充侧面／背面用于结构参考，不宣称来自已经建立的 3D 模型或正交测量。

## 首批十状态与既有代码映射

动作沿用 `SelahFlutter/lib/domain/selah_enums.dart` 的现有枚举，不扩展动作 ID。

| 状态 | 既有动作 | 视觉与后续动效意图 |
| --- | --- | --- |
| 待机 | `gentleFloat` | 稳定自然站姿，轻微呼吸 |
| 眨眼 | `blink` | 在原眼位短暂闭眼 |
| 叶片轻摆 | `leafSway` | 叶根固定，只小幅摆动叶片 |
| 准备聆听 | `listenEnter` | 清楚专注的眼神，一次小幅回应 |
| 播放中 | `listenPlaying` | 安静陪听，不持续跳跃 |
| 聆听完成 | `listenComplete` | 弯眼微笑，轻微点头 |
| 录音中 | `recRecording` | 睁眼专注，不假装随音频做口型 |
| 录音完成 | `recDone` | 柔和微笑或轻抬小手 |
| 复习顺利 | `quizGood` | 一次小幅庆祝，保持身体比例 |
| 再试一次 | `quizFail` | 温和鼓励，不哭泣、不萎蔫、不惩罚 |

V4 图中的「休息」保留为表情补充，当前不新增第十一个业务动作。

## 运行接入与验收边界

Web 当前使用 `SeedPlushAtlas.png`，实际为 1254 × 1254 RGB 图集。身体和手脚共层、叶片独立，Flutter 按实测轮廓裁切背景；五官、阴影和成长装饰在统一 1000 × 1200 坐标系中绘制。原图仍有背景，独立透明 PNG 输出继续列为待办；不得将其用于需要真实 alpha 的外部素材交接。独立生成的姿态不保证逐像素相同，不能轮播十张独立图片代替稳定动画。

控制器已接入播放准备、播放中、真实音频自然结束、录音、转写成功和复习结果；闲置包含眨眼与叶摆。成功反馈只在对应业务完成后触发，1400 毫秒后归位。待机与陪听可轻微循环，其余动作一次播放；Reduce Motion、后台生命周期和 TickerMode 禁用时停止动画。旧 `SelahSprite` 仅保留在原生入口。

正式页面使用小头像、手机陪伴位、174 像素侧栏角色和 210 像素引导角色；独立预览使用同一正式组件检查十动作及五个成长阶段。身体不随状态重新生成或拉伸，叶根和眼位固定。五个成长阶段已沿用原记录并接入叶片、布花苞和布花；独立高清成长素材仍属导出待办。

设计图完整性与 Web 动画验证分开记录。当前 Flutter 自动化通过，浏览器已检查宽窄屏、滚动、真实音频状态、Reduce Motion 和断网加载；实体设备、真实麦克风／云端转写尚未验收。具体证据和剩余项见 `docs/web-plush-acceptance.md` 与 `docs/next-development.md`。
