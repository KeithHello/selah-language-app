# Selah 设置、界面语言与本机能力设计

> 本文保留最初的设计决策轨迹。2026-09-10 的合并实施补充已覆盖本文中关于“界面语言／母语”分开设置的旧描述；最终行为以文首的合并方案和代码实现为准。

**产品目标：** 设置页把语言角色说清楚。用户只选择一次“母语”，选项为繁体中文、简体中文、日本語；该选择同时决定界面显示语言和之后输入使用的语言，默认繁体中文。学习语言区显示英语和日本語两个选项，英语当前可用，日本語灰色禁用并标注「之後準備加入」，实际目标语言仍固定为英语。本机存储、安装和更新按真实浏览器状态呈现。

**依据：** 主人 2026-09-10 认可的设置改善方向，「界面需要繁体中文、默认显示繁体中文」，以及随后「日语作为母语和界面语言」。工程边界见 [项目规范](../../../CLAUDE.md) 与 [Flutter／Web 约定](../../../SelahFlutter/CLAUDE.md) 。实施分解见 [界面语言计划](../plans/2026-09-10-interface-language-plan.md) 与 [设置／PWA 计划](../plans/2026-09-10-settings-pwa-plan.md) 。

## 合并实施补充（2026-09-10，最终方案）

- 设置页只保留一个“母语”选择，不再提供独立的“界面语言”控件。可选值为 `zh-Hant`（繁体中文）、`zh-Hans`（简体中文）和 `ja`（日本語），默认值为 `zh-Hant`。
- `nativeLanguage` 是唯一持久化字段；`uiLocale` 只作为代码兼容读取器，始终由 `nativeLanguage` 派生，不再写入快照。这样可以避免用户选择互相矛盾的“界面语言＋母语”组合。
- 选择会立即更新界面文案，并决定之后的输入、转写和生成路由：两个中文选项都使用 `sourceLanguage: 'zh-Hant'`、转写 `language: 'zh'`；日本語使用 `sourceLanguage: 'ja'`、转写 `language: 'ja'`。学习语言控件显示英语（当前可用）和日本語（灰色禁用、标注「之後準備加入」），实际目标语言继续固定为 `en`。
- 旧快照迁移规则：明确的 `ja` 保留日本語；旧 `nativeLanguage: 'zh'` 搭配 `uiLocale: 'zh-Hans'` 迁移为 `zh-Hans`；其他中文或缺省／非法值迁移为 `zh-Hant`。迁移后只写回 `nativeLanguage`。
- 已保存句子的正文、`sourceLanguage`／`targetLanguage`、音频缓存键和复习数据不因选择变化而回写。同步或导入时本机合法选择优先，云端不新增语言字段。
- 语言卡片顺序为「母語」三选一、说明文字、「學習語言」双选项。英语为当前选中且可用，日本語保持灰色禁用并标注「之後準備加入」。PWA 的保护本机、安装到主屏幕和更新状态设计保持本文后续章节不变。

## 学习语言控件补充（2026-09-10）

- 设置页恢复英语／日本語的双选项布局，英语显示为当前可用项，日本語使用禁用态并在右侧显示「之後準備加入」。
- 本期不开放日语课程，学习语言仍由生成合约固定为 `en`，不新增 `targetLanguage` 偏好字段；该控件用于表达已支持与规划中的语言范围。
- 日语选项不可点击，不触发保存、路由或句子变更；后续开放日语课程时再接入独立目标语言偏好和生成／音频能力。

## 1．当前工程事实

- 正式 Web 设置在 `SelahFlutter/lib/web/ui/web_learning_app.dart` 的 `_SettingsPage`。现有分组是陪伴、提醒、账户与同步、数据与离线。没有语言分组。
- 偏好模型 `LearnPreferences` 以 `nativeLanguage` 保存唯一语言选择，默认 `zh-Hant`；`uiLocale` 只作为派生兼容读取器，不再单独持久化。
- 生成／整理链路固定学习语言 `en`；中文选项使用 `sourceLanguage: 'zh-Hant'` 和转写 `language: 'zh'`，日本語选项使用 `sourceLanguage: 'ja'` 和转写 `language: 'ja'`。启动页 `index.html` 与 PWA `manifest.json` 默认繁体。
- 句子对象已有 `sourceLanguage`／`targetLanguage` 溯源字段。切换界面不得改写这些字段，也不得改音频缓存键 `id:voice:hash`。
- 循环听设计把句子角色叫「学习语言／母语」，并按句子实际语言名展示。设置里开放母语后，新句子可以是日语→英语；已有中英句子仍按自身语言播放，不回写、不混译。
- 「保护本机存储」先读取 `navigator.storage.persisted()`，已保护时显示只读状态，否则才提供申请并在失败时提示导出备份。
- 「安装到主屏幕」按安装状态展示只读、可一键安装、iOS 手动步骤或浏览器菜单说明；已独立窗口打开时不再保留安装主按钮。
- 「发现新版本，更新应用」只在 `platformInfo.updateAvailable` 为真时出现，设置页常驻显示 Build ID，更新前会检查未保存输入、录音和练习评分；Service Worker 只对 waiting worker 应用更新。
- 云端 `user_profiles` 当前字段是声线、语速、引导完成和提醒，没有界面语言列。本期不新增 migration。
- 现有 Web 中文字体只打包 `Noto Sans SC`。繁体汉字与日语假名／汉字的覆盖必须单独验收；补繁体或日文字体属于依赖／资源确认项，不是本轮执行授权。

## 2．语言角色

产品仍区分三个语言角色，但设置只提供一个不会产生冲突的“母语”选择；界面语言由该选择自动派生，学习语言区显示英语和日本語，其中日本語暂不可用。

| 角色 | 产品含义 | 本期行为 |
| --- | --- | --- |
| 界面语言 | 按钮、导航、说明、系统弹窗、启动页、错误提示、可访问名称 | 由“母语”选择自动派生：`zh-Hant` 繁体、`zh-Hans` 简体、`ja` 日本語 |
| 母语 | 用户输入、转写、释义、循环听里的母语音轨角色 | 唯一可改设置：`zh-Hant` 繁体中文、`zh-Hans` 简体中文、`ja` 日本語 |
| 学习语言 | 生成句、英文声线、学习音频、循环听里的学习音轨角色 | 英语为当前可用并选中；日本語灰色禁用并标注「之後準備加入」，不开放第二课程 |

副文案随母语变化，不要写「选择任意语言」：

- 母语中文：「你用中文说出想法，Selah 帮你变成能开口的英语。」
- 母语日语：「日本語で思ったことを話すと、Selah が話せる英語にしてくれます。」

选择母语会立即切换应用文案，并只影响**之后**的输入、转写、整理和生成：两个中文选项继续使用 `sourceLanguage: 'zh-Hant'` + 转写 `language: 'zh'`；日语选项使用 `sourceLanguage: 'ja'` + 转写 `language: 'ja'`。学习语言仍是 `en`。已保存句子的正文、`sourceLanguage`／`targetLanguage`、音频缓存键都不回写。循环听按每句自己的语言角色播放，中英句和日英句可以共存在同一句库，但不能把旧中文句当成日语母语去生成母语音频。

## 3．默认与恢复

1. 唯一的母语选择支持：`zh-Hant`、`zh-Hans`、`ja`。默认 `zh-Hant`；界面语言从同一值派生。
2. 两个中文选项都代表中文输入，生成源语言代码仍用现有 `zh-Hant`；简繁只控制界面文案与选项显示。
3. 首次使用、没有字段的旧快照、非法值、空值：界面和母语都回落繁体中文。
4. 不读取浏览器或系统语言来改默认。日语浏览器也应先看到繁体中文界面和母语选项“繁体中文”，直到用户明确选择。
5. `nativeLanguage` 是本机账户快照的唯一语言字段。访客和登录账户各自保存。登录、同步、导入备份不得用云端缺省值覆盖本机已有的明确选择。
6. 云端 profile 暂时不同步该字段。合并时本机合法值始终胜出。
7. 启动页 HTML、loading、`<html lang>`、manifest 默认繁体。用户选择简体或日语后，已启动的应用立即切文案；静态 HTML／manifest 可保持构建时的繁体默认。不把「需要重新安装 PWA 才换语言」写成产品要求。
8. 界面语言和母语不再独立选择；三种母语选项分别对应一种界面语言，避免出现用户无法理解的混合组合。

## 4．设置信息架构

设置页顺序改为：

1. 语言
2. 陪伴
3. 提醒
4. 账户与同步
5. 备份与离线
6. 本机与应用

「安装到主屏幕」不再是设置页唯一实心主按钮。陪伴里的「保存」名字仍可以是该卡片内的主操作。语言卡片的简繁切换用等权选项，不要用珊瑚色强调简体。

### 4.1 语言卡片

- 标题：語言／语言／言語
- 控件：母語。三个等权选项「繁體中文」「簡體中文」「日本語」，选中态同时用对号和文字，不只靠颜色，不用珊瑚色强调某一项。该选择同时控制界面文案和之后的输入语言。
- 说明：明确写出「母語會同時決定介面顯示，以及之後輸入使用的語言。」（按当前界面语言提供对应翻译）。
- 学习语言控件：显示「英語」和「日本語」两个选项；英语为当前可用项，日本語禁用并在旁边显示「之後準備加入」。
- 界面切换立即保存并刷新可见文案。失败时保持原选择并显示错误，不出现一半语言一半语言的导航。
- 母语切换立即保存，但只作用于之后的输入／转写／生成。若当前句库已有另一种语言的句子，用一句说明：「已保存的句子保持原来的语言；新输入将使用日本語／中文。」不提供一键翻译旧句。
- 切换母语不中断正在播放的英文学习音频。循环听若已开始，本轮仍按开播时冻结的句子语言播放；新母语从下一轮准备生效。

### 4.2 备份与离线

保留导出备份、导入备份、离线说明。保护、安装、更新从这里移走。离线说明继续诚实：「種子內容和已快取的音訊可以離線使用；新產生內容需要網路。」

### 4.3 本机与应用

三项都是状态行，不是并列日常按钮。

**保护本机存储**

| 状态 | 展示 | 操作 |
| --- | --- | --- |
| 已保护 | 空間不足時，瀏覽器不應自動清掉本機紀錄 | 无按钮 |
| 未保护 | 可申請持久保存，減少被自動清理的機會 | 「申請保護」一次 |
| 不支持 | 這個瀏覽器沒有持久儲存。請定期匯出備份 | 无申请按钮 |
| 申请失败 | 瀏覽器尚未授予持久儲存 | 可再试一次，并强调导出备份 |

申请前读取 `persisted()`。已保护就不要反复把按钮画成待办。文案不得承诺「学习记录更不容易丢」或「关掉网页也能提醒」。用户手动清除站点数据、无痕模式和私密浏览仍会丢掉本机数据。

**安装到主屏幕**

| 状态 | 展示 |
| --- | --- |
| 已安装（standalone 或 iOS `navigator.standalone`） | 只读「已加入主畫面」 |
| 可一键安装（有 `beforeinstallprompt` 且未安装） | 次要按钮「加入主畫面」。说明：像应用一样打开，少一些浏览器工具栏 |
| iOS Safari／未安装 | 展开三步：分享 → 加入主畫面 → 打开图标。不假装能弹出系统安装框 |
| 其他不支持 | 说明可在浏览器菜单里寻找「安裝應用」或「加入主畫面」；桌面 Chromium 可提示地址栏图标 |

主路径仍是用户已经用过一次之后的轻提示或设置后备。设置页不在已安装状态继续放主按钮。

**版本与更新**

- 常驻显示当前 Build ID（构建脚本写入的 `selah-build-id`）。没有新版本时文案是「目前已是這個版本」。
- 只有 Service Worker 正在等待时才出现「更新到新版本」。不要用「發新版本」。
- 更新前仍须：完成本机保存、结束录音／转写、没有未提交练习评分。多窗口时，一个窗口更新会重载所有同源窗口；确认框必须写明这一点。
- 任意页在检测到等待中的 worker 时，可以出现一条非打断式更新条。设置页是后备，不是发版后台。
- 允许设置里提供「檢查更新」，它只调用 `registration.update()` 并汇报真实结果：已是最新、发现新版本、或当前浏览器不支持。

## 5．界面文案覆盖范围

必须随 `uiLocale` 切换的，包括但不限于：

- 导航：今天／聆聽／練習／筆記／設定 及其简体、日语对应
- 引导、Today、聆聽、練習、筆記、設定、登入／註冊、管理台
- 控制器提示、`LearningFailure` 产品文案、同步状态、离线说明
- 分类、声线、复习状态、词汇状态、成长阶段标签、回忆标题（即使入口暂时隐藏，文案表仍要覆盖）
- 系统 `AlertDialog`、`TimePicker` 需要 `flutter_localizations` 的 `zh-Hant`／`zh-Hans`／`ja` Material 文案
- 启动页 loading、可访问名称、通知标题

母语为日语时，输入框标签、占位和引导要从「写下今天的一句话」改成日语输入语境，例如「今日の一言を書いてください」。这是母语文案，不是界面语言的副作用；界面日语 + 母语中文时，输入框仍是中文语境。

不翻译、不改写的：

- 用户输入的中文或日语原文、生成出的英文、种子句双语正文
- 邮箱、Build ID、技术错误码
- 精灵用户起的名字

简繁与日语均用人工对照，不在运行时调用 OpenCC 或在线翻译。专名 Selah 保持拉丁字母。

## 6．数据与同步

`LearnPreferences.nativeLanguage`：

- 合法值：`zh-Hant`、`zh-Hans`、`ja`
- JSON 缺省或非法 → `zh-Hant`
- `zh-Hant`／`zh-Hans` 在生成请求中都映射为 `sourceLanguage: 'zh-Hant'`，转写映射为 `language: 'zh'`
- 日语母语映射为 `sourceLanguage: 'ja'`、`language: 'ja'`
- 学习语言本期固定 `en`，不进偏好字段

旧快照中的 `uiLocale` 只用于一次迁移，迁移后不再序列化。明确的 `nativeLanguage` 优先；旧 `nativeLanguage: 'zh'` 与 `uiLocale: 'zh-Hans'` 迁移为 `zh-Hans`，其余旧中文组合迁移为 `zh-Hant`。

共同规则：

- `updatedAt` 仍表示整份偏好写入时间；统一母语选择切换时更新它
- 导入备份时，非法值丢弃并回落默认，不整份拒绝备份
- 访客快照与登录快照隔离。`importGuest` 不覆盖当前账户已明确保存的母语选择
- 云端 profile 暂时不同步该字段。不要把它塞进未约定列。跨设备同步另开 schema 确认

## 7．PWA 状态机

桥接 `platformInfo` 扩展为：

- `online`、`installed`、`canInstall`、`updateAvailable`（已有）
- `storagePersisted`: `true`／`false`／`null`（null 表示 API 不存在）
- `installKind`: `installed`／`prompt`／`ios-manual`／`unsupported`
- `buildId`: 读取 `meta[name=selah-build-id]`

`persistentStorage` 先 `persisted()`，已是 true 就直接返回 true；否则 `persist()`。不要在 Web Worker 里调用 `persist()`。

`install` 仅在存在 deferred prompt 时调用 `prompt()`。iOS 路径只展示说明，不调用不存在的 API。

`applyUpdate` 继续向 waiting worker 发送 `APPLY_UPDATE`，并在 `controllerchange` 后 reload。禁止向 active worker 发这条消息。

## 8．依赖与字体

若采用 Flutter 官方本地化（推荐，因为时间选择器和 Material 按钮会跟语言走）：

- 允许的最小依赖说明：`flutter_localizations`（SDK）和 SDK 约束下的 `intl: any`
- `supportedLocales` 含 `zh-Hant`、`zh-Hans`、`ja`
- 先写进计划，实施前仍需主人确认这一项项目依赖变更
- 不引入 `easy_localization`、生成式翻译服务或新的全局包管理工具

字体：

- 现有 `Noto Sans SC` 不能自动当作繁体或日语覆盖完成
- 实施前用真实繁体文案（「聽／練／設／語」）和日语文案（含ひらがな、カタカナ、常用漢字）做缺字检查
- 若缺字，提出最小方案：`Noto Sans TC` 和／或 `Noto Sans JP`，列入资源确认；未确认不得打包新字体

服务端：

- 现有生成函数已接受 `sourceLanguage` 字符串，缺省才是 `zh-Hant`。客户端改发 `ja` 不自动等于 prompt 已按日语教学改写。
- 实施母语日语时，必须核对 `sentences-generate`／`sentences-prepare`／`sentences-batch-generate` 在 `sourceLanguage=ja` 时的输出合约：日语原文、英语译文、英语拆解、中文或日语释义策略。若当前 prompt 把源语言写死为中文，先改 prompt／合约再对用户开放开关。
- 转写已允许 `language=ja`。客户端在母语为日语时发送 `ja`。
- 种子句仍是中英。日语母语用户可以跳过中文种子、只从 Today 输入开始，或继续选用现有中英种子；不得把中文种子伪造成日语。
- 日语母语的 TTS／循环听母语音频是后续能力，不在界面语言完成定义里。没有日语音频时，循环听对日英语句应明确「母语音轨未准备好」，不能用浏览器朗读冒充。

## 9．非目标

- 不开放英语界面，也不开放韩语等未点名的语言
- 学习语言仍是英语。不开放「学日语」课程，不把旧中英句一键改成日英句
- 不把界面语言绑定到生成 `sourceLanguage`。日语界面可以继续用中文母语学习英语
- 不修改数据库 schema、密钥、CI、公开部署
- 不把循环听开发、日语 TTS 预制、Web Push 或真机发布验收并进本计划的完成定义
- 不把「保护本机」宣传成加密或云备份

## 10．验收合约

| ID | 要求 |
| --- | --- |
| L01 | 无偏好的首次进入，应用文案、导航、启动页默认繁体，母语为中文 |
| L02 | 选择三种母语之一后立即切换对应界面，刷新后仍保持该选择 |
| L03 | 浏览器语言为简体或日语也不能在无偏好时改掉默认繁体中文 |
| L04 | 切换母语／界面后，已有句子正文和语言元数据不变 |
| L05 | 登录／同步／导入备份不覆盖本机已保存的母语选择 |
| L06 | 设置语言卡片只展示一个三选一的母语控件和只读的学习语言 |
| L07 | 选择日语母语后，之后的生成／转写发送 `ja`；已有中英句子不被改写或重译 |
| L08 | 选择中文选项时输入框是中文语境；选择日本語时输入框是日语语境 |
| P01 | 已保护存储不再显示待办主按钮 |
| P02 | 已安装 PWA 不再显示安装主按钮 |
| P03 | iOS 显示手动步骤，不调用 `beforeinstallprompt` |
| P04 | 无等待中的 worker 时不显示「更新到新版本」 |
| P05 | 有未保存输入或录音时拒绝更新，并给出可理解原因 |
| P06 | 安装与保护的文案不承诺防丢数据和后台提醒 |

静态设计稿不是本轮交付物；设置改版以现有 Quiet Growth 卡片、字号和 760px 内容宽为视觉约束。
