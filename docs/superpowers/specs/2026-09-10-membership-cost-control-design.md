# Selah 会员、试用与费用保护设计

日期：2026-09-10。状态：可审阅的开发依据；收费功能与保护机制尚未实施。

配套：[开发计划](../plans/2026-09-10-membership-cost-control-plan.md) 、[交互展示稿](2026-09-10-membership-cost-control-ui.html) 、[交付总结与八张界面图片](2026-09-11-membership-delivery.md) 。

## 1．最终产品方案

采用「免费示例＋7 天限额试用＋39.9 元月会员」。限制新增 AI 处理，鼓励学习已有内容。用户购买前能看清完整权益；日常学习不出现剩余额度、已用数量、消耗进度条或月底用完提醒。

| 权益 | 免费示例 | 个性化试用 | 月会员 |
|---|---|---|---|
| 有效期 | 长期可学习 | 首次个人表达生成成功并在服务端保存后 168 小时 | 每个服务端确认的付费账期 |
| 价格 | 免费 | 免费，每个账户一次 | 人民币 39.9 元／月 |
| 新增个人表达 | 不提供 | 30 条 | 300 条 |
| 新增 AI 配音 | 复用示例音频 | 3000 个字符 | 30000 个字符 |
| 录音转写 | 不提供 | 5 分钟 | 60 分钟 |
| 长文整理 | 不提供 | 3 次 | 30 次 |
| 已有内容学习与复习 | 可用 | 到期或触顶后仍可用 | 到期或触顶后仍可用 |

四项额度分别计算，不能互相兑换。配音按实际提交供应商的文本计量，包含标点、空格、母语和英语音轨；新声线和主动重新配音也计入。一个批次生成几条，按成功保存的条数计数；长文整理本身不自动消耗表达条数，后续确认生成表达时再计算。转写按服务端验证的音频时长计量，不按用户声称的时长计量。

首版按主动购买／续购设计，不默认自动扣款。支付渠道尚待商户条件确认；本设计不声称已接入任何具体渠道，也不增加年费、加量包或多档会员。

## 2．核心机制一览

| 编号 | 机制 | 处理方式 | 用户看到什么 |
|---|---|---|---|
| M01 | 试用与账期 | 试用首次服务端保存成功后起算；月会员以支付核验结果建立账期 | 会员状态和到期日期，无用量倒计数 |
| M02 | 权益展示 | 购买前列完整静态上限和计量口径，日常页面隐藏用量数字 | 「查看方案说明」；正常学习不被打扰 |
| M03 | GPT 说明 | 生成入口与方案页说明实际使用 OpenAI GPT；配音单独披露 AI 合成 | 用途与来源说明，无准确率保证 |
| M04 | 服务端准入 | 所有付费入口统一校验身份、有效期、权益、费用和平台预算 | 只在相应操作不能继续时解释原因 |
| M05 | 并发与重复请求 | 事务预占、唯一请求键、负载哈希、一次性发送认领 | 连点、刷新、跨设备不会重复消费 |
| M06 | 失败、重试与对账 | 最多增加一次供应商尝试；每次另预占费用；未知费用保守占用 | 可以恢复已完成结果，失败不冒充成功 |
| M07 | 批量和输入限制 | 按实际条数控制输出；验证完整文本、录音与音轨 | 操作前说明单次格式／长度限制 |
| M08 | 支付可靠性 | 验签、金额和订单核对、幂等发权益；续购不立即刷新当前额度 | 待核验、已到账、失败、退款各有状态 |
| M09 | 资源与平台保护 | 模型总预算、试用池、存储、下载流量、异常熔断分别管控 | 服务异常与本人权益用完使用不同提示 |
| M10 | 运营核查 | 复用现有管理员用量账，展示预占、实际、未知与账单差异 | 详细用量仅管理员可见 |

## 3．状态、账期与权益口径

### 3.1 试用

账户具备资格时可以发起首次个人生成。第一次付费请求之前创建一次性的试用预备记录并分配费用预算；失败不会创建新的赠送预算。首次个人表达结果在服务器持久化时，同一事务激活试用并保存 `started_at` 与 `expires_at = started_at + 168h`。客户端是否仍在线、是否确认收到，不影响起算；后续重试可取回该结果。

试用时段使用 `[started_at, expires_at)`。首次请求失败不占成功表达条数，已发生的供应商费用仍记在同一试用预算。仅做转写／整理而未生成个人表达时，时间尚未开始，但预备期额度与费用照常消耗，不能靠停留在预备期得到无限处理。账户仅有一个试用记录，删除本机数据、退出登录、换设备不重置。多账户滥用由试用池总预算、注册准入与现有身份校验控制，不能宣称单靠账户唯一性消灭多开。

### 3.2 月会员

以支付渠道服务端验证到账的时间为首个账期起点。一个月为一历月，UTC 存储，界面按用户时区显示明确日期；月末采用锚点日截到当月末，再于后续月份恢复原锚点。例如 1 月 31 日开通，下一边界为 2 月末，再下一边界为 3 月 31 日。

有效期内主动续购排到下一账期，不立即清空本期消耗。自然月首日、客户端改时钟、重新登录均不重置。前一账期已预占的在途请求仍结算到前一账期，不能挪到新账期重复扣除或免费重放。购买时说明下一期开始日期；没有已购买的下一期时，提示「本期结束后续购可继续生成」，不承诺自动恢复。

试用转付费从支付核验成功起建立新付费账期；试用余额不叠加，旧试用在途请求仍结算原记录。退款撤销相应未生效或仍有效的付费权益，保留账务事件与既有学习内容；补偿以单独审计事件记录，不篡改历史消耗。

### 3.3 成功与计量

| 场景 | 用户权益 | 平台费用 |
|---|---|---|
| 新表达生成并服务端保存成功 | 消耗成功条数 | 记录所有已发送尝试 |
| 长文整理并保存可恢复结果 | 消耗一次整理 | 记录文本 token 费用 |
| 转写完成并保存结果 | 消耗经验证音频时长 | 按实际计费数据结算；未知则保留上界 |
| 新配音成功入库并建立可恢复音频记录 | 消耗实际新增配音字符 | 包含新语言音轨／新声线／主动重生成 |
| 复用同一结果或播放本机缓存 | 不消耗生成权益 | 不新增模型费用 |
| 云端重新下载已有音频 | 不消耗生成权益 | 仍可能产生下载流量成本 |
| 供应商已收费、结果保存失败 | 不扣未交付权益，优先恢复输出 | 不把平台费用退为零 |
| 超时且不知是否已收费 | 未交付部分先保持预占，待确定后释放权益 | 继续保守占用该尝试最高可能费用 |

“已有内容可学习”不等于“任意云端无限下载”。本机缓存可离线学习；服务故障时未缓存音频可能暂时无法下载，文字与已缓存音频继续可用。不能为了费用保护删除用户已有内容。

## 4．UI／UX 展示与文案

展示稿默认繁体中文，沿用 Selah 的奶油底色、珊瑚主按钮、鼠尾草绿与薰衣草辅助色。正式接线遵守现有界面语言计划：默认 `zh-Hant`，支持 `zh-Hans` 与 `ja`；语言切换不改历史内容、权益、账期或音频缓存键。

### 4.1 页面和展示位置

| 位置 | 展示内容 | 交互原则 |
|---|---|---|
| 方案页 | 试用／月会员静态权益、价格、起算、续购方式、GPT 说明 | 一次看清；不虚构折扣、倒计时或自动续费 |
| 日常输入 | 输入框、生成按钮、轻量 GPT 来源说明 | 不放用量仪表盘；生成中禁重复提交 |
| 账户／会员 | 当前方案、有效期、续购入口、方案说明 | 可查看静态权益，不返回或展示剩余额度 |
| 额度触顶 | 当前受限类别、准确恢复条件、可以继续的行为 | 在用户发起相应操作时提示；其他类别仍可用 |
| 试用到期 | 39.9 元会员入口、继续学习已有内容 | 不锁住历史内容，不自动扣款 |
| 支付核验 | 正在核验、已到账、失败或退款 | 回到页面不等于已到账；可查单，避免重复付款 |
| 费用保护／服务异常 | 暂时无法新增、草稿保留、已有缓存可复习 | 不显示「你的额度用完了」，不借故引导重复购买 |

### 4.2 模型提示

主文案：「使用 OpenAI GPT 模型生成與整理學習內容，協助你練習自然英文。」

生成入口短标识：「OpenAI GPT 內容輔助」。辅助说明：「AI 生成內容，請結合語境確認。」配音说明：「語音由 AI 合成。」

实际文字模型保持 `gpt-4o-mini`；转写保持 `gpt-4o-mini-transcribe`；配音保持 `tts-1`。来源声明从受控模型配置映射，不让客户端自报模型；切换模型必须同时检查来源文案与价格。不能把 `tts-1` 标成 GPT 配音，也不能把模型名称当作百分之百正确、人工审核或官方背书。

质量保证来自语种检查、结构化结果校验、长度约束、代表性语言样本评估与失败处理，不只是一行标识。自动修复也算供应商重试，不允许“直到 JSON 正确为止”的无界循环。

### 4.3 状态文案合约

| 状态／错误码 | 繁体文案示例 | 行动与反馈 |
|---|---|---|
| `trial_expired` | 「你的試用已結束。已建立的內容仍可繼續學習。」 | 「開通月會員 · ¥39.9」／「繼續學習」 |
| `feature_limit_reached`，配音且已续购 | 「本期新增配音已達上限，將於 10 月 10 日 09:00 恢復。已生成的音頻仍可聆聽。」 | 「聆聽已有內容」；日期来自服务端 |
| `feature_limit_reached`，配音且未续购 | 「本期新增配音已達上限。本期於 10 月 10 日 09:00 結束，續購後可在下一期繼續生成。」 | 「查看續購」／「聆聽已有內容」 |
| `request_exceeds_feature_limit` | 「這次內容超過本期可新增配音的範圍，請縮短內容後再試。」 | 保留输入；不能把未全部用完说成全部用完 |
| `rate_limited` | 「操作有些頻繁，請稍後再試。」 | 返回 `retryAfterSeconds`；保留草稿，不扣权益 |
| `generation_in_progress` | 「內容正在處理，完成後會保留在這裡。」 | 禁止重复按钮；用同请求查询结果 |
| `payment_pending` | 「正在確認付款結果，請勿重複付款。」 | 「重新查詢付款」；可离开后恢复 |
| `payment_failed` | 「付款尚未完成，會員尚未開通。」 | 查询订单确认失败后才允许新订单 |
| `service_budget_protected` | 「新增內容服務暫時無法使用。你的草稿已保留，仍可複習已儲存的內容。」 | 返回学习；运营补偿另行审计，不扣未交付权益 |
| `offline` | 「目前離線。你可以先記下想說的話，連線後再生成。」 | 本机草稿；不离线发放权益 |

试用只给具体到期时间，不显示倒数几天。会员到期日期可以常驻，因为它说明服务期限；不显示「还剩 X 条／分钟／字符」。静态权益说明可以一直打开。对“查看用量”的客服诉求可以提供经核实的记录，不以隐藏主界面为由拒绝解释限制；产品首版不建设余额面板。

### 4.4 可访问性与响应式

正常文字对比度至少 4.5∶1，按钮触控区域至少 44×44 像素。珊瑚底按钮使用深色文字。所有输入有标签，键盘焦点可见，对话框可用 Escape 退出并恢复焦点。成功反馈使用礼貌播报，受限提示在操作后可被读屏感知。320／390／768／1440 像素宽、横屏和 200％ 文字放大时内容完整；不禁止缩放。遵守 Reduce Motion，不做倒计时、闪烁或促销式动效。

## 5．服务端保护设计

### 5.1 统一准入流程

所有上游调用仅允许发生在受控服务端路径。适用入口包括单句、批量、长文整理、转写、配音、修复与重试；任何未来新增入口也必须注册到同一策略。客户端不得指定价格、预算、会员身份或任意上游模型。

```text
验证身份与请求 → 查已有结果／缓存 → 验证输入及单次费用上界
  → 原子预占「用户权益＋用户费用＋平台日／月费用＋试用池费用」
  → 持久化一次性发送凭证 → 认领一次供应商调用
  → 保存结果与实际计费证据 → 幂等结算／保守挂账
```

缓存命中无新增上游调用，但仍验证内容归属。每层预算均满足下式才允许发送：

```text
已结算费用 + 未决尝试的费用上界 + 本次调用的费用上界 <= 该层预算
已交付权益 + 在途预占权益 + 本次需要权益 <= 该项权益上限
```

费用使用整数 `nano_usd`（十亿分之一美元）保存，API 中以十进制字符串传输；不得使用浮点累加。预占费用向上取整，人民币预算换算为美元可用额时向下取整。请求记载实际使用的价格版本和汇率保护版本，方便对账。

售出权益版本按账期保留；供应商价格不能假定被账期锁定。每次请求使用当前已验证且未过有效期的保守费率，价格变化／汇率越过保护区间／模型路由变化时暂停相关新调用并重新验证预算。不能继续使用过时低价估算。

### 5.2 并发、幂等与故障

- 同一账户、业务操作、请求 ID 建唯一约束并保存负载哈希；同 ID 不同负载返回冲突，不另发模型请求。幂等不以当前账期为查找前提，跨期重放仍找到原结果与原账期。
- 事务按固定顺序锁全局预算、试用池、用户账期与请求，先确认所有层都有空间再共同预占；不能先检查后分开写入，不能只靠前端按钮或 Edge 内存锁。
- 在持久化预占之后，通过数据库 CAS 获取一次性发送认领。重复工作进程不能共同发出同一 attempt；失去租约的旧工作进程不能再次发送或覆盖新状态。
- 发送后的超时、断网或进程退出不能按 TTL 自动清空费用；只有确定未发送的请求才可直接释放全部费用。发送情况不明时宁可挂账，依靠证据对账，不推测“应该没扣钱”。
- 每个业务操作最多一个首发和一个额外供应商尝试。重试新建 attempt，并再次预占所有费用预算；不把自动格式修复藏成免费调用。用户主动重新生成是新操作，仍受全套权益／费用／速率限制。
- 供应商结果已经取得时，数据库保存／Storage 上传重试复用这份结果。保存成功、前端未收到时允许按请求 ID 取回，不重新生成。
- 对账只在得到可验证的真实计费数据后释放多余费用；未知金额保留保守上界，并在管理员界面显式标识。运营手动处理必须有原因和审计轨迹。

### 5.3 输入、批量和语音

| 路径 | 约束与实施要求 |
|---|---|
| 单句生成 | 延续 sourceText 最多 500 字符和目标句最长 1000 的输入／结构约束；把完整 system、schema 与 user 输入计入 token 上界，单条输入预算 4096、输出最多 2048 tokens |
| 长文整理 | 输入最多 4000 字符；完整输入预算 16384、输出最多 4096 tokens；最多输出 20 段，每段最多 500 字符 |
| 批量生成 | 每批 1—5 条；完整输入按待生成条数界定，输出上限改为 `min(n * 2048, 8192)`；不得让单条沿用固定 8192；一次预占所有待处理条数，逐条结算成功部分，整批模型费用只记录一次 |
| token 验证 | 使用与模型一致的计数方法或有证明的保守上界；不是把用户字符数当成输入 token 数。缺少可信计数时拒绝该付费入口，不凭估算发送 |
| 配音 | 从当前用户拥有的句子与音轨记录取服务端文本；声线／模型在白名单内。按实际送上游的完整文本、供应商计费字符定义预占；新增母语音轨与更换声线单独消耗，缓存键包含文本版本、语言、模型和声线 |
| 转写 | 服务端校验容器、编码、真实时长与文件大小；现有 180 秒／10 MiB 单次约束继续有效；伪造 durationMs 不影响计量。必须证明该模型单次收费上界，不能把每分钟估算价当保证 |
| 音频交付 | 上传前预占字节；单个 MP3 初始拟定 5 MiB 上限，需以最长合法内容验证后定稿；超界保存失败仍保留已发生的 TTS 费用。不得以超界为由循环重做配音 |

当前每分钟速率约束可作为初始防刷策略，但必须拆开长文整理与转写计量，避免共享旧 `capture_preparation` 配额。现有每日 20 条等限制不能未经说明继续成为隐藏会员权益限制：首版去掉低于账期权益的业务日额度，保留公平的并发／分钟级防刷限制，并在方案说明中说明连续操作可能需稍候。

极短录音、多个碎片、空白文本、批量部分失败、不同语言的 token 比例都属于成本边界样本。次数型开销不能被分钟或字符上限掩盖；如需新增最短时长或单期次数约束，必须先修改公开权益说明，不能上线后暗加。

### 5.4 支付与安全

支付创建订单时只接收受控 SKU，服务端决定 `3990` 分人民币。签名验证、商户、币种、金额、订单、账户归属、支付终态全部吻合后才能发权益。支付事件唯一；乱序的旧成功事件不能覆盖退款终态。客户端返回页、截图或客户端传入的 `paid=true` 都不发权益。

订单和会员接口仅返回本人的必要数据。费用账、价格配置、管理明细仅服务端与授权管理员可读写；复用当前 RLS／管理员授权，不向客户端暴露 service role 或供应商密钥。日志只保留请求标识、计量证据与脱敏错误，不记录用户原文、录音、密钥或完整上游错误体。

### 5.5 平台与资源费用

除单人模型预算外，还要配置模型日／月总预算、试用获客费用池、账户准入、存储总量与流量限额。没有有效预算配置或预占数据库不可用时，拒绝新增付费调用；不能退化为无检查调用。

准入侧为已接受的会员和试用保留预算余量；总预算不足时先停止新增试用／销售，避免用售出后频繁熔断代替可履约预算。监控通知只是辅助，真正拒绝必须在发送之前生效。多账户也不能突破总试用池。

音频 bucket 保持私有。短时签名 URL 可以重复下载，单纯限制签名次数无法严格限制流量。若要执行下载字节限额，客户端须通过授权下载网关读取；按对象大小或单一 Range 长度预占，拒绝多 Range，未知中断保守计入，复用本机缓存。客户端不拿到可重复绕过网关的源站 URL；切换时把旧签名有效期内的流量单独留出预算。网关自身的调用和出站费用也计入基础设施预算。

固定云服务、计算规格、已启用附加项、税费、支付渠道费和异常请求的基础设施成本独立核算。Supabase Spend Cap 仅覆盖部分用量项，不能将其宣传成任意金额的总账单硬上限。任何供应商控制台设置或 Cloudflare 操作都须依照项目规则逐步说明并确认，本文不执行配置。

## 6．预算数字与上线门槛

以下为上轮估算的复核基准：USD／CNY 按 7 计算，只是预算假设，不是当前汇率。价格采用已查官方表：`gpt-4o-mini` 输入／输出每百万 tokens 为 0.15／0.60 美元，`tts-1` 每百万字符 15 美元；转写每分钟 0.003 美元仅为估算。按第 5.3 节文本边界测算，不能代表当前代码已具备边界。
