# Selah 循环听最终产品规则

日期：2026-09-15

本文补充 [2026-09-10 循环听 UI／UX 设计](2026-09-10-loop-listening-design.md)，并吸收 2026-09-15 页面调研结论。循环听产品规则以本文为准；与 2026-09-10 设计或 2026-09-15 修正计划草稿冲突时，按本文执行。

## 1．本轮要达到的使用结果

未登录用户完成引导后，可以在「聆听 → 循环听」里选语序、选停止时间（含自定义分钟）、准备已经在本机的双语音频，再开始循环播放，到时安静停止。

已登录用户使用同一套界面和同一套会话，循环听不因登录状态被藏起或禁用。登录只用来给尚无本机音频的个人句子补齐 TTS，以及同步。

首次见面只需名字和至少 3 句种子。推荐按钮给出 3 句当前 starter 包里已有中英／中日母语音频的句子。

## 2．新增规则

### R17 登录不是循环听门槛

无论是否登录，用户都可以使用循环听／重复听。这不是新的播放模式，就是现有「循环听」：进入模式、选语序、选时长、准备已有双语音轨、开始、暂停、下一句、定时停止。

登录只用于：

- 给尚无缓存、也无法从种子包命中的个人句子调用 `audio-generate` 或刷新签名 URL。
- 云同步。

明确禁止：

- 把循环听入口、设置卡或开始按钮藏在登录墙后面。
- 未登录时调用 `audio-generate` 或 `audio-download-url`。
- 用 `gateway.configured` 代替 `hasSession`。本地 Web 注入了公开 Supabase 配置后，`SupabaseLearningGateway.configured` 恒为 true，访客仍是 `userId == null`、账户为 `guest`。
- 用英文音轨、浏览器朗读或 Mock 充当母语。
- 静默跳过缺音频的句子，却声称已经播完整句库。

未登录且当前句库都是带齐双语包的种子：必须能完整准备并循环，不出现登录要求。

未登录且队列里有需要生成的个人句子：保留循环听界面和已选语序／时长，主按钮停在「准备音频」或「重试缺失音频」，文案为「登录后就能补齐个人句子的循环听音频」，可带登录入口。不得把这种情况收成「暂时无法完成操作，内容已保留，请稍后重试。」

已登录且音频已在本机：准备与开始不得仅仅因为已登录就再打一遍生成接口。

### R18 引导至少 3 句

首次引导：取名字，再至少选择 3 句种子即可开始。仍可多选，没有额外上限，只受当前 10 句 starter 库限制。

推荐按钮一次选 3 句，且必须是当前包里已有英文四声线和中文／日语母语 MP3 的 ID：

- `seed-001`
- `seed-006`
- `seed-012`

这三句覆盖工作、朋友、生活日常。若某次运行的种子列表缺其中一句，再按当前 `seeds` 顺序补足 3 句，不得再指向已删除的 `seed-003`／`seed-005`／`seed-007`／`seed-009`。

已完成引导的本机数据不改写句数、不自动删句。R18 只约束新的引导门槛和推荐按钮。

校验失败文案改为「请选择至少三句想学的表达。」三语文案同步。

## 3．仍要修好的既有交互

这些规则维持 2026-09-10 设计 S01／S04／S05 和 2026-09-15 调研结论，本轮一并做完。

| 项 | 当前问题 | 目标 |
| --- | --- | --- |
| 自定义时长 | 「自定义」chip 用当前分钟和自己比较，永远选中；`custom && !selected` 永假，弹窗不可达。页面上 30 分钟与自定义会一起打勾。 | 点自定义永远打开数字输入。15／30／60／自定义四选一。接受 1～720 整数分钟。取消保持原值。输入正好是 15／30／60 时选中对应预设。其它合法值显示「自定义 · N 分钟」。不自动开播。 |
| 准备／开始 | `startLoop()` 内部准备完立刻 `audioLoopStart`。 | 缺轨时主按钮「准备音频」；齐了才是「开始循环听」。准备结束不得自动出声。 |
| 音频刷新 | 循环听用 `GET audio-download-url`，接口只收 POST。 | 与单句播放一样走 POST。未登录不走这条。 |
| 报错 | JS 下载／校验失败和网关异常被收成通用粉条。 | 映射到缺母语、需登录、需联网、地址刷新失败、校验失败。 |
| 本机 URL | `_ensureLoopAudio` 拒绝非 https，会打挂 `http://127.0.0.1` 种子文件。 | 允许本机 `http://127.0.0.1` 与 `http://localhost`；远端签名 URL 仍要 https。 |
| 改序／截止 | 暂停改序可能重放当前语言；播放中没有独立截止计时器。 | 改序从下一句生效；首段真实 `playing` 后记下截止，到期立刻停当前音轨。 |

自定义不做成 `HH:MM` 或秒级输入。产品定时单位是分钟。

## 4．种子与客户端现实

本地 starter 已是 10 句、60 条清单、20 个母语文件。键为 `seed-xxx:<voice>`、`seed-xxx:source:zh-Hant`、`seed-xxx:source:ja`。中文母语即使界面是简体，清单键仍是 `zh-Hant`。

未登录循环听的完整双语条件就是这 10 句。本轮不生成其余 20 句母语，不把英文 MP3 改名冒充母语。

应用内浏览器仍可能挂着旧 Build `818ec9378df88fcb`，本机服务已提供 `3c5e4fd11eb124c6`。本地验收前必须先更新或硬刷新，确认页面 `v=` 已不是旧值。更新失败按更新链路处理，不记成循环听缺陷。

## 5．明确不做

- 新的「重复听」独立模式、随机播放、白噪音、运行中改时长。
- 未登录批量 TTS、付费补齐其余种子母语。
- 数据库 schema、密钥、CI、Cloudflare Pages、真机锁屏 60 分钟。
- 改写已引导用户的句库。

## 6．验收标准

用未登录、简体界面、引导只选 3 句（推荐的 001／006／012 或任意 3 句 starter）：

1. 引导在 3 句时可以开始；2 句不行。
2. 点「自定义」弹出分钟输入，能存 45，也能改回 30。
3. 循环听不要求登录。
4. 双语未进缓存时按钮是「准备音频」；准备成功后变成「开始循环听」，不会自己出声。
5. 开始后按「英语 → 中文」循环，到时停下。
6. 不再用通用粉条代替「缺母语」或「登录后补齐个人音频」。
