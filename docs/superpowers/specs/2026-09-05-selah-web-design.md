# Selah Web 设计与交付边界

主人于 2026-09-05 确认上轮可行性方案，并授权先整理开发计划，再完整实施 Web 客户端。

## 产品

Flutter Web 作为主客户端，Supabase 承担认证、持久化和 AI 网关。保留 Swift 原生客户端。Web 延续 Quiet Growth 暖米色与珊瑚色设计，沿用现有 PNG 分层精灵。桌面为侧栏、主学习区与陪伴信息，手机为单列与底部导航。

未登录也能学习正式 seed 内容，并在本机保存学习记录。登录后使用真实 AI 服务和账户云同步。新句子不得由 Fixture、固定英文或浏览器合成语音冒充 AI／TTS。没有远端配置时显示可用的本地学习入口与明确的连接状态。

页面包括首次命名和选取三个 seed、今日表达与长文分段、聆听与理解、开口自评复习、句子笔记和词汇、成长回忆、设置与数据备份。练习采用原版 new→learning→familiar→quiet 状态与 clear／almost／failed 信号。中断播放不能计为聆听完成。

## 技术边界

- 新 Web 代码放在 `SelahFlutter/lib/web/`，入口经条件导入，原生 SQLite 与 Fixture 不进入 Web 编译图。
- 使用现有 Supabase SDK，逐字段适配七个已存在的 Edge Functions；不新增 Flutter 包。浏览器能力经标准 `dart:js_interop` 和自有小型 JS 适配层接入。
- IndexedDB 保存版本化、按账户分区的学习快照；音频用 Cache API 保存并校验 SHA-256。服务工作线程缓存应用壳与静态资源，不能缓存认证响应或 AI POST。
- 云端读取／写入现有 sentences、vocab_items、companions、sprite_memories、user_profiles、learning_events。保留 ID、时间和复习状态，按更新时间合并；退出账户后立即切换本地分区。同步失败保留本地修改，不能清空本机数据。
- JSON 备份先校验版本、大小、ID 和关联关系，再幂等合并。旧 iOS 数据通过明确的导出格式导入；不宣称网页能直接读取 iPhone 的 SwiftData 沙箱。
- 麦克风只在用户操作后请求，录音有时长上限并在结束／异常时释放轨道。服务端转写沿用用户认证和额度约束，不上传原始录音到学习事件。
- Web Push 需要独立订阅持久化与服务端定时触发。需要新增 schema 的部分先提供具体设计，取得确认后再写迁移；不把页面内计时提醒说成关闭网页后也能准点送达。
- 默认不执行线上迁移、密钥修改、CI 修改、发布或 Git push。

## 验收

本地自动化覆盖真实接口字段、空输入、失败重试幂等、复习状态、备份无效输入与重复导入、账户隔离、合并冲突和音频完成信号。浏览器验证首次进入、种子选取、真实播放、练习、搜索、导入导出、刷新持久化、窄屏和离线加载。正式 AI 与跨设备验收需要可用的 Supabase 登录和服务端密钥，分别记录，不能以 mock 测试替代。
