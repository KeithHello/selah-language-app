## 本次纠偏

- 旧十姿态图存在高矮、宽窄和脚部间距变化，手臂由身体侧面移到正面，叶片形态与叶根位置不稳定。
- Web 运行图片存在过大透明留白、独立叶片图标与身体错位；本次图片修订不将当前导出图作为形体参考。
- 采用原 C 版的平滑哑光、轻体积感，避免粗糙毛毡／黏土颗粒、强反光和过大的独立球形手脚。
- 各状态保留同一圆润轮廓、眼距、嘴部位置、肢体连接点和单芽阶段；表情、微小整体倾斜及叶尖摆动负责表达状态。
- 本轮修订取代旧试点中的明显纵向拉伸、高跳旋转等视觉参考，不变更动作 ID 或学习业务。

## 交付目录与验收

`design-system/selah/mascot/` 保存版本化标准图、状态总览、图像提示词和验收记录。使用内置图像生成工具；原始参考图与现有运行素材保留。

先生成单个标准角色，目视核对原始 C 版后，以该标准图派生十状态总览。检查身份一致性、完整肢体、叶柄连接、表情语义、状态标签及缩小后的可读性。AI 状态图是视觉验收稿，不能宣称已经具备逐像素一致的动画骨骼或可直接裁切的序列帧。
