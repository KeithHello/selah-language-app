# C 短绒角色 Web 验收

日期：2026-09-05。主人批准 C 设计包后实施。本文记录当前本地客户端，不代表云端服务或手机真机已经验收。

## 交付与边界

- 正式 Web 页面使用 C：燕麦奶油短绒身体、刺绣五官、鼠尾草叶片。引导页、手机陪伴位、头像和桌面陪伴栏共用 `PlushCompanion`。
- 同一母版驱动十个既有动作，不切换独立生成的姿态，不拉伸身体。身体与手脚共层，叶片绕固定叶根摆动，五官随身体移动。
- 五个成长阶段沿用既有学习记录，叶片／布花苞／布花连接同一头顶锚点；不新增成长规则。
- 圆形开始按钮为 64 逻辑像素，滚动时固定可达；姓名非空、恰好三句且非忙碌才启用。输入错误／保存失败显示在按钮上方。姓名最后填写也会立即更新启用状态。
- 宽屏陪伴栏内容可滚动，底部回忆操作固定；累计练习文案改为「累计生长」。启动加载页使用品牌叶芽，避免旧角色闪现。
- 开发预览直接使用正式组件，支持十动作重播、减少动态效果和五个成长阶段。没有增加正式产品路由、角色切换、依赖或视频运行时。

素材仍有一个明确缺口：`SeedPlushAtlas.png` 为 1254 × 1254 RGB，1654171 字节。两次图像工具调用未输出真实 alpha；当前由 Flutter 依据实测轮廓裁切背景，在已测大小下正常显示。原始文件不是透明 PNG，独立 RGBA 导出和高清成长素材继续列在 Roadmap。

图集 SHA-256：`318FD51848B121E8A79811767E428070490DC6F87E6C5ECC1D3F12138660B98D`。实际提示词、来源和限制见 `design-system/selah/mascot/prompts-c-web-runtime.md`。原生 Swift／Flutter 入口不随本轮替换角色。

## 十动作的运行行为

| 动作 | 触发与实际表现 |
| --- | --- |
| `gentleFloat` | 空闲时 7.2 秒柔和浮动，包含短暂眨眼与小幅叶摆；170 像素角色的最大浮动约 2.4 像素 |
| `blink` | 独立 280 毫秒眨眼，保持眼位；日常待机中也会出现 |
| `leafSway` | 1.4 秒轻摆一次，叶根固定；待机中包含更小幅叶摆 |
| `listenEnter` | 音频准备时一次微动，提示准备聆听 |
| `listenPlaying` | 真实音频播放时 3.6 秒轻微起伏，保持专注表情 |
| `listenComplete` | 真实自然结束且记录保存成功后弯眼微笑、轻抬一次 |
| `recRecording` | 录音成功开始后微动一次并保持专注，不根据假音量张嘴 |
| `recDone` | 转写实际成功后微笑；取消、权限拒绝或失败不触发成功 |
| `quizGood` | 顺利复习保存成功后庆祝一次，170 像素角色最大抬升约 4.6 像素 |
| `quizFail` | 需要再练时轻微回应并鼓励，保持完整轮廓 |

一次性结果提示在 1400 毫秒后回到待机，同一事件不因 rebuild 重复播放；新的同类事件通过 revision 重新触发。录音／播放业务状态优先，切换账户和取消流程清理旧反馈。Reduce Motion 停止循环和位移，保留静态表情；后台生命周期和 TickerMode 禁用时停止动画。

## 浏览器实测

使用 Codex 内置 Chromium 浏览器。5181 为原本页面，仅刷新版本；5183 为隔离测试来源，命名、选句、播放和速度改动只写入该来源的测试学习记录。

- 1280 像素宽屏：角色、叶片与五官无棋盘底、错位或拉伸；真实引导选三句并开始成功。列表滚动后 64 像素按钮坐标保持不变。最终原页面再次滚动两屏复查，开始按钮前后均为 x=1010、y=1182、64 × 64；该次为应用默认视口，随后已恢复滚动位置。
- 390 × 844 手机视口：顶部 C、学习卡片和底部导航正常；320／820／900／960 宽度另外通过 Flutter 布局测试。
- 最终版本 1280 × 600：三个已解锁回忆仍可滚动查看，「查看全部回忆」位于 y=544—580，保持在视口内。
- 真实内置 MP3：准备 → 陪听 → 自然结束反馈 → 待机；真实播放完成后计数增加一次。实际观察到「准备好了，陪你一起听」「我在认真听」「又听懂了一点」三个业务提示。
- 浏览器 `prefers-reduced-motion` 模拟开启后，两次角色区域截图字节相同；关闭后恢复。生命周期暂停另外由 widget 测试覆盖。
- 缓存后使用 CDP 阻断网络，以不进入 Service Worker 缓存的 `/api/selah-offline-probe` 请求返回 `Failed to fetch` 确认断网生效；重新加载页面、角色图集和缓存 MP3 可用，播放结束后练习计数从 5 增至 6。图集传输为 0、解码字节为 1654171。完成后恢复网络。
- 应用内「发现新版本，更新应用」→「现在更新」成功，活动 Service Worker 版本为 `c09b325e7f7fb159`；六次练习及原先三条种子记录保留。原页面缓存亦已切换到最终版本。
- 最终页面读取的浏览器 error／warn 日志为空。预览十状态和五阶段已目视检查。

手机视口模拟不代表 iPhone Safari、实体麦克风、软键盘、长时间性能、系统省电或 PWA 安装已通过。
