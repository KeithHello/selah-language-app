## 后续开发判断

### Edge Function

应当作为第二阶段，而不是在当前 401 未解决时并行改线上路径。计划是让 `audio-generate` 接收并校验源语言与供应商元数据：`zh-Hant` 路由到 Azure，英语保留现有 OpenAI 路由；缓存键加入供应商、声线、语速和版本，错误时不伪造成功；补齐合约、缓存命中和供应商失败测试后，再单独确认远端函数部署。

### 英语口音

首期默认 `en-US`，原因是日本与台湾用户通常更容易接触到、跨地区教材兼容性较高；不为每句同时生成英音和美音，避免首批音频数量与成本翻倍。后续把 `en-GB` 作为可选声线配置，并把口音作为声线／缓存维度，待有真实使用需求后再扩充。

## 待主人确认

- 重新配置同一 Azure Speech 资源的凭证后，只需回复「已重新配置」，即可继续十条音频生成与本地重建。
- 新音频生成成功后，音质是否可接受必须由主人实际试听确认；代码和 HTTP 校验不能替代主观听感验收。
