## 内容和平台边界

- 随包包含 30 条真实种子文本和 11 段现有音频，覆盖默认声线的 8 条种子及种子 001 的另外 3 种声线。其余音频仍需恢复现有后端后获取，没有额外生成计费音频。
- 提交后的文本草稿保存在 IndexedDB；未转写的录音仅保留当前页面会话，刷新或换账户会清除。备份不含录音与音频文件。
- Web 备份／导入已经实现。旧 iOS SwiftData 本地历史的专用导出器尚未实现，不能声称旧设备全部数据已迁入 Web。
- 页面运行时的提醒已接线。后台 Web Push 还需订阅表、RLS、VAPID 和调度服务，具体设计见 [Web Push 上线方案](web-push-plan.md) 。
- `speech-transcribe` 源码与合约测试已完成，尚未加入函数部署配置或部署。步骤见 [语音转写服务](web-speech-service.md) 。
- 现有 Swift 业务未修改，本轮未运行 Swift／Xcode；iPhone Safari、实体麦克风、系统安装／通知、移动网络首屏性能与正式 HTTPS 托管仍待验收。
